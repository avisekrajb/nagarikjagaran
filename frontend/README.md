# Nagarik News — Premium Nepali News Frontend

A complete React.js + Create React App + Tailwind CSS + React Router + Framer Motion frontend for a modern Nepali news portal.

## Run
```bash
npm install
npm start
```

Build:
```bash
npm run build
```

## Highlights
- Nepali-first premium newspaper UI
- Responsive desktop/tablet/mobile layouts
- Sticky responsive header + mobile drawer
- Home, 8 category routes, article routes and search
- Mock Nepali news data, weather widget and reels viewer
- Reusable services, hooks, context and utils
- Framer Motion hover/entry animation
- No backend/database and no Vite

All requested source folders/files are preserved.
